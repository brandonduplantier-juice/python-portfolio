# LiveLab Exercises

A set of nine hands-on practice notebooks, each a self-contained mini-project on a
different real dataset. These are skill-building exercises that demonstrate range
across data loading, cleaning, analysis, visualization, and a couple of small
programming challenges.

## What it is
Foundational practice work, kept for completeness. Each notebook takes a fresh dataset
or problem and works it end to end in Python and pandas. Honest framing: these are
learning exercises, not flagship projects, and they are here to show breadth and
fundamentals.

## The notebooks
- `LL-Build-Up-Nepal.ipynb` - analysis of the Build Up Nepal dataset.
- `LL-Fresh-Monster.ipynb` - Amazon activity data analysis.
- `LL-Headspace.ipynb` - Headspace app usage data.
- `LL-National-Parks.ipynb` - US National Parks recreation-visit trends.
- `LL-SkullcapzStudios.ipynb` - a studio analytics exercise.
- `LL-T-Swift.ipynb` - exploring a Taylor Swift discography dataset.
- `LL-TheRecordingAcademy.ipynb` - Recording Academy social-post analysis.
- `LL-TicTacToe.ipynb` - a Tic-Tac-Toe implementation (Python logic practice).
- `LL-Wordle.ipynb` - a Wordle-style game (Python logic practice).

## Data
The supporting CSVs live in `datasets/`; supplementary files are in `files/`.

## How to run
Open any notebook in Jupyter or VS Code and run the cells top to bottom. Each is
independent, so they can be run in any order.
